## STRIKE SYSTEM — HOW PENALTIES WORK

### Strike Levels
```
WARNING (1st offense) → No penalty. One-time courtesy. Does not expire.

STRIKE 1 → Upload ban: 7 days. No livestream.
STRIKE 2 → Upload ban: 14 days. No livestream.
STRIKE 3 → CHANNEL TERMINATED. Permanent. All videos deleted.
```

### Strike Expiry
- Each strike expires after **90 days** IF you complete YouTube's required training module
- 3 strikes within 90 days = instant termination regardless of training

### Immediate Termination (No Warning, No Strikes)
These violations = channel deleted instantly:
- Child sexual abuse material (CSAM)
- Severe harassment / doxxing
- Terrorist content
- Coordinated fraud at scale
- Creating new channel after termination to bypass ban

### 2.3 Words/Phrases That Trigger Demonetization

**NEVER use these in title, thumbnail, or opening 30 seconds:**
```
- "guaranteed returns" / "guaranteed profit"
- "get rich quick" / "make money fast"
- "risk-free investment"
- "secret method" (in financial context)
- specific stock/crypto "will moon" / "will pump"
- "I made $X in X days" (unverified claims)
- any currency amount in title implying guaranteed earnings
```

**USE INSTEAD:**
```
- "how this investment strategy works"
- "what the data shows about X"
- "understanding X (and the risks)"
- "why most people fail at X"
- "the truth about X"
```

### 2.4 Finance Channel Specific — YMYL Rules
Finance = "Your Money or Your Life" category. YouTube + Google apply stricter standards.

**Required in EVERY finance video:**
- Verbal disclaimer: *"This video is for educational purposes only and is not financial advice."*
- Written disclaimer in description (first 3 lines, before "show more")
- No specific investment recommendations framed as advice
- All statistics must be sourced and verifiable
- No exaggerated earnings claims without documented proof

**High-risk phrases for YMYL finance channel:**
```
BANNED phrases:
- "You WILL make money if..."
- "This stock IS going to..."
- "I guarantee..."
- "100% safe investment"
- "Experts are WRONG about..."  ← OK only if you cite evidence

SAFE phrases:
- "Historically, this type of investment has..."
- "According to [source], the data shows..."
- "One approach some investors use is..."
- "The risk with this is..."
- "Past performance doesn't guarantee future results"
```

## SECTION 3: COPYRIGHT RULES

### 3.1 Strike System for Copyright
```
COPYRIGHT CLAIM (Content ID) — NOT a strike
  → Advertiser revenue goes to rights holder
  → Video stays up
  → Can dispute if fair use applies

COPYRIGHT STRIKE — Formal DMCA takedown
  → Strike 1: 7-day upload ban
  → Strike 2: 14-day upload ban
  → Strike 3: Channel terminated
  → Strikes expire after 90 days
```

### 3.2 What Triggers Copyright

| Content Type | Risk Level | Safe Alternative |
|---|---|---|
| Commercial music (any) | VERY HIGH | Royalty-free: Pixabay, YouTube Audio Library |
| News clips | HIGH | Link in description, quote briefly |
| TV show clips | HIGH | Short clips <10 sec with commentary |
| Stock charts (from Bloomberg/Reuters) | MEDIUM | Generate own charts from raw data |
| Podcast clips | MEDIUM | Get permission or use <10 sec |
| Movie clips | HIGH | Avoid entirely |
| Other YouTube videos | HIGH | Never re-upload, brief clip with commentary only |
| Books/text | MEDIUM | Paraphrase + cite |
| Images from Google | HIGH | Use Pexels, Unsplash, Pixabay only |

### 3.3 Fair Use — When You're Protected
Fair use applies when ALL of these are true:
1. You **transform** the content (add commentary, analysis, criticism)
2. You use only the **minimum necessary** portion
3. Your use does not **harm the market** for the original
4. It's **educational, commentary, or parody**

Fair use is a legal defense — YouTube won't protect you automatically. Strike still comes first.

### 3.4 Safe Music Sources for Video Agent

```
FREE + SAFE:
- YouTube Audio Library (youtube.com/audiolibrary)
- Pixabay Music (pixabay.com/music)
- ccMixter (ccmixter.org)
- Free Music Archive (freemusicarchive.org)

PAID + SAFE (no claims ever):
- Epidemic Sound (~$15/mo)
- Artlist (~$16/mo)
- Musicbed (~$16/mo)
```

## SECTION 4: AI CONTENT POLICY (2026)

### 4.1 What YouTube Detects and Penalizes

YouTube does NOT scan for AI writing directly.
YouTube detects **patterns** of inauthentic, low-effort content:

| Signal | Risk Level |
|---|---|
| Same video template every upload | HIGH |
| Synthetic voice + stock footage + no human value added | HIGH |
| Mass uploads (10+ videos/day same format) | TERMINATION |
| No commentary, no opinion, no transformation | HIGH |
| Channel-wide format similarity | HIGH |
| Undisclosed AI voice/face on realistic-seeming content | HIGH |

### 4.2 AI Disclosure — When MANDATORY

You MUST toggle "Altered or synthetic content" disclosure in YouTube Studio when video contains:
- AI-generated voiceover that sounds like a real, identifiable person
- AI-generated face/deepfake of real person
- Synthetic re-creation of a real event that didn't happen
- AI-generated footage presented as real documentary footage

You do NOT need to disclose:
- AI-assisted script writing
- AI-generated thumbnails (unless realistic fake person)
- AI tools used for editing, captions, color grading
- Stylized/clearly artificial AI animation

### 4.3 What Makes AI Content Safe (Our System Does This)

| Risk Factor | Our Mitigation |
|---|---|
| Mass production | 1 video/week only |
| Identical templates | 3 rotating script templates |
| No human value | Real data + strong opinions + unique angle |
| Synthetic voice | Disclose in metadata when used |
| No transformation | Every video analyzes real financial data |
| No variation | Varied structure, length, format per video |

### 4.4 Inauthentic Content — Banned Formats

**NEVER produce:**
- AI-generated slideshows with no narration structure
- Verbatim readings of Wikipedia or news articles
- Compilation videos of other people's content
- Videos where only title/thumbnail changes, body is identical
- "Top 10" lists with zero original analysis
- AI music loops over static image (no voiceover)

## SECTION 6: METADATA RULES (Title, Description, Tags, Thumbnail)

### 6.1 Title Rules

**ALLOWED:**
- Curiosity gaps: "Why 90% of investors fail"
- Data-driven: "The $47 trillion shift changing finance"
- How-to: "How to build passive income (realistic timeline)"
- Opinion: "I was wrong about index funds"

**NOT ALLOWED:**
- Exaggerated earnings: "I made $50,000 in 30 days" (unverified)
- False scarcity: "Watch before YouTube deletes this"
- Misleading: "Secret banks don't want you to know" + video is basic finance 101
- All-caps excessive: "YOU WILL BECOME A MILLIONAIRE"
- Fake urgency with no basis: "URGENT: Your savings at risk NOW"

### 6.2 Thumbnail Rules

**ALLOWED:**
- Bold text with clear topic
- Facial expressions (surprise, concern) matching content tone
- Charts/graphs from video
- High contrast, readable text

**NOT ALLOWED:**
- Thumbnail shows different person/event than video
- Arrows pointing to fake circles on photos of real people
- Fake screenshots of bank accounts (unverified)
- Sexually suggestive imagery
- Graphic violence
- Thumbnails that contradict video content

### 6.3 Description Requirements (Finance Channel)

Every video description MUST contain:
```
Line 1-3 (before "show more"):
"[VIDEO TOPIC] — Educational content only. 
Not financial advice. 
For informational purposes only."

Body:
- Video chapters with timestamps
- Data sources cited (links)
- Any affiliate links disclosed ("affiliate link" label)
- Sponsor disclosure if applicable ("paid partnership")
- Channel links, social media

Footer:
"DISCLAIMER: This video is for educational and entertainment 
purposes only. Nothing in this video constitutes financial, 
legal, or tax advice. Always consult a qualified professional 
before making financial decisions. Past performance does not 
guarantee future results."
```

### 6.4 Tag Rules
- Use relevant tags only (no tag stuffing unrelated terms)
- No competitor channel names in tags
- No misleading tags to appear in unrelated searches
- Max 500 characters total

## SECTION 7: SPONSORSHIPS & AFFILIATE DISCLOSURES

### 7.1 Mandatory Disclosures

If video includes any paid promotion:
1. **Verbal disclosure** in first 30 seconds: "This video is sponsored by X"
2. **YouTube paid promotion checkbox** must be checked in YouTube Studio
3. **Description disclosure**: "Sponsored by [Brand]" at top
4. FTC rules apply regardless of location if targeting US audience

### 7.2 Affiliate Links

```
In description: "* Affiliate links below — I earn commission at no cost to you"
Label each link: "[AFFILIATE] Best broker I use: [link]"
Do NOT: hide affiliate nature of links
Do NOT: fake reviews for affiliate products
```

### 7.3 What Violates Disclosure Rules
- Promoting a product without disclosure
- Saying "I personally use X" when paid to say it
- Fake unboxing/review when product was gifted
- Undisclosed integrated ads within video content

## SECTION 10: EMERGENCY PROCEDURES

### If Channel Gets Strike
```
1. Do NOT upload anything for 24 hours
2. Read the strike notice in YouTube Studio carefully
3. Complete the required training module (starts 90-day expiry clock)
4. Appeal if violation is incorrect:
   Studio → Content → find video → Appeal
5. Do NOT delete the video (doesn't remove strike)
6. Do NOT create new channel
7. Notify human operator immediately via Telegram
8. Orchestrator pauses all automation until human reviews
```

### If Video Gets Demonetized (Yellow $)
```
1. Read the specific reason in YouTube Studio
2. Edit the issue (title, thumbnail, or request manual review)
3. Request manual review: Studio → Monetization → Request review
4. If denied: edit content and re-upload (new video, same script)
5. Note: manual review takes 1-30 days
6. Agent logs which content type caused it → avoids in future
```

### If Copyright Claim (Not Strike) Received
```
1. Check: is it a claim (revenue redirect) or strike?
2. If claim only: decide whether to dispute or let rights holder take revenue
3. If disputing: only dispute if you have clear fair use argument
4. If strike: evaluate counter-notification option
   - Only counter-notify if you're certain of fair use
   - False counter-notification = perjury risk
5. Agent logs the specific content that caused claim → blacklists for future
```
